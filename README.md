# Interactive Periodic Table

An interactive periodic table web application built using HTML, CSS, and JavaScript.

This project displays chemical elements in a visually engaging animated layout with a clean interface.

## Features

- Interactive periodic table layout
- Animated UI design
- Responsive web interface
- Modern visual presentation

## Technologies Used

- HTML5
- CSS3
- JavaScript
